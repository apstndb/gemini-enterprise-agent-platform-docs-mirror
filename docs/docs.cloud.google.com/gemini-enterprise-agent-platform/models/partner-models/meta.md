Muse models from Meta are available for use as managed APIs on Agent Platform. You can stream your responses to reduce the end-user latency perception. A streamed response uses *server-sent events* (SSE) to incrementally stream the response.

## Managed Meta models

The following models are available from Meta to use in Agent Platform. To access a Meta model, contact your Google Cloud account manager or go to [https://dev.meta.ai/contact-sales](https://dev.meta.ai/contact-sales?utm_source=google_cloud&utm_medium=partner&utm_campaign=muse_spark_1_3&utm_content=model_page) for Preview access.

### Muse Spark 1.3 from Meta

Muse Spark 1.3 from Meta is a reasoning model trained for agentic workflows and competitive coding. It delivers higher first-attempt accuracy, reliable built-in tool calling with MCP support, and 1M-token long context for multi-step tasks.

Contact your Google Cloud account manager or go to [https://dev.meta.ai/contact-sales](https://dev.meta.ai/contact-sales?utm_source=google_cloud&utm_medium=partner&utm_campaign=muse_spark_1_3&utm_content=model_page) for Preview access.
