A TensorboardTimeSeries data point.

Fields

`wallTime` `string ( `[`Timestamp`](https://protobuf.dev/reference/protobuf/google.protobuf/#timestamp)` format)`

Wall clock timestamp when this data point is generated by the end user.

Uses RFC 3339, where generated output will always be Z-normalized and use 0, 3, 6 or 9 fractional digits. Offsets other than "Z" are also accepted. Examples: `"2014-10-02T15:01:23Z"` , `"2014-10-02T15:01:23.045123456Z"` or `"2014-10-02T15:01:23+05:30"` .

`step` `string ( `[`int64`](https://developers.google.com/discovery/v1/type-format)` format)`

Step index of this data point within the run.

`value` `Union type`

Value of this time series data point. The following is a list of mutually exclusive fields. At most one of the fields will be set in a response:

`scalar` `object ( `[`Scalar`](https://docs.cloud.google.com/gemini-enterprise-agent-platform/reference/rest/v1beta1/TimeSeriesDataPoint#Scalar)` )`

A scalar value.

`tensor` `object ( `[`TensorboardTensor`](https://docs.cloud.google.com/gemini-enterprise-agent-platform/reference/rest/v1beta1/TimeSeriesDataPoint#TensorboardTensor)` )`

A tensor value.

`blobs` `object ( `[`TensorboardBlobSequence`](https://docs.cloud.google.com/gemini-enterprise-agent-platform/reference/rest/v1beta1/TimeSeriesDataPoint#TensorboardBlobSequence)` )`

A blob sequence value.

End of mutually exclusive fields.

**JSON representation**

```
{
  "wallTime": string,
  "step": string,

  // value
  "scalar": {
    object (Scalar)
  },
  "tensor": {
    object (TensorboardTensor)
  },
  "blobs": {
    object (TensorboardBlobSequence)
  }
  // Union type
}
```

## Scalar

One point viewable on a scalar metric plot.

Fields

`value` `number`

value of the point at this step / timestamp.

**JSON representation**

```
{
  "value": number
}
```

## TensorboardTensor

One point viewable on a tensor metric plot.

Fields

`value` `string ( `[`bytes`](https://developers.google.com/discovery/v1/type-format)` format)`

Required. Serialized form of <https://github.com/tensorflow/tensorflow/blob/master/tensorflow/core/framework/tensor.proto>

A base64-encoded string.

`versionNumber` `integer`

Optional. version number of TensorProto used to serialize [`value`](https://docs.cloud.google.com/gemini-enterprise-agent-platform/reference/rest/v1beta1/TimeSeriesDataPoint#TensorboardTensor.FIELDS.value) .

**JSON representation**

```
{
  "value": string,
  "versionNumber": integer
}
```

## TensorboardBlobSequence

One point viewable on a blob metric plot, but mostly just a wrapper message to work around repeated fields can't be used directly within `oneof` fields.

Fields

`values[]` `object ( `[`TensorboardBlob`](https://docs.cloud.google.com/gemini-enterprise-agent-platform/reference/rest/v1beta1/TensorboardBlob)` )`

List of blobs contained within the sequence.

**JSON representation**

```
{
  "values": [
    {
      object (TensorboardBlob)
    }
  ]
}
```
